# באולינג שערי חדרה — אתר

אתר תדמית סטטי, שמונה עמודים, עברית RTL.
בנוי ב-Astro ונפרס לוורסל אוטומטית בכל push ל-`main`.

**דומיין:** `www.all4fun.co.il`

---

## למה Astro ולא HTML רגיל

האתר הקודם היה שישה קבצי ASP נפרדים, וכל שינוי בטלפון או בשעות הפתיחה
היה צריך לקרות בשישה מקומות. בפועל זה אף פעם לא קרה בכל השישה, והאתר
הסתובב עם פרטים סותרים.

כאן ההדר, הפוטר וכל הפרטים יושבים במקום אחד. הפלט עדיין HTML סטטי לגמרי —
אפס JavaScript של פריימוורק נשלח לדפדפן.

---

## עריכה שוטפת

רוב השינויים לא דורשים נגיעה בקוד:

| מה לשנות | איפה |
|---|---|
| טלפון, פקס, אימייל, כתובת | `src/data/site.json` |
| שעות פתיחה | `src/data/site.json` → `hours` |
| תפריט הניווט | `src/data/site.json` → `nav` |
| נתיבי הלוגואים | `src/data/site.json` → `logoMain`, `logoAtb` |
| מחירי ימי הולדת ומה כלול | `src/data/packages.json` |
| תמונות | `public/images/` |
| תפריטים ודפי חבילות | `public/pdf/` |

שינוי ב-`site.json` מתעדכן בכל שבעת העמודים בבת אחת.

להחלפת תמונה: להעלות קובץ חדש **באותו שם** ל-`public/images/`.
אין צורך לגעת ב-HTML.

## פריסה

וורסל, Framework Preset: **Astro**. אין מה להגדיר מעבר לזה.

ההפניות מהאתר הישן יושבות ב-`vercel.json`. אלה 301 קבועות שמעבירות
את דירוג הגוגל מהכתובות הישנות לחדשות — **לא למחוק**:

```
/default.asp, /Default.asp    →  /
/about.asp                    →  /about
/birthDay.asp, /birthday.asp  →  /birthdays
/bar.asp                      →  /bar
/hobby.asp                    →  /classes
/contact.asp                  →  /contact
/Menu102023.pdf               →  /pdf/Menu102023.pdf
/images/<שם>.pdf              →  /pdf/<שם>.pdf   (עשרת תפריטי האירועים וחבילות ימי ההולדת)
```

הדומיין רץ 25 שנה. מחיקת ההפניות תאפס את מה שנצבר בהן.
ההתאמה ב-vercel.json רגישה לאותיות גדולות/קטנות, ולכן יש כניסה
נפרדת לכל איות שהאתר הישן קישר אליו.

### DNS

נבדק 01.11.2026. הדומיין רשום אצל InterSpace (internic.co.il) על
"bowling gan shmuel Ltd", מייל ניהולי tibi00@netvision.net.il,
**תוקף עד 15.12.2026 — לחדש**. שרתי השמות אצל Dropper
(ns1/ns2.dropper.co.il), ואת הרשומות משנים רק בפאנל שלהם.

היום: `A @ → 5.144.49.50` (השרת הישן), `CNAME www → apex`, TXT SPF.
אין רשומת MX — המייל העסקי הוא תיבה של netvision ולא תלוי בדומיין.

פרויקט הוורסל של האתר (`all4fun-site`, פריסה אוטומטית מ-GitHub)
יושב בחשבון הוורסל `bowlinggsil`, לא בחשבון האישי. לפני שינוי DNS
מוסיפים שם את הדומיין לפרויקט (Settings → Domains: `all4fun.co.il`
ו-`www.all4fun.co.il`) ולוקחים משם את הערכים המדויקים. הגנריים:

```
A      @      76.76.21.21
CNAME  www    cname.vercel-dns.com
```

ב-TXT/SPF לא נוגעים. **לא להעביר nameservers לוורסל** — אין בזה
צורך, והחזרה לאחור אורכת יום-יומיים במקום שעה.

## דברים ששוברים אם נוגעים בהם

**jQuery.** נטען ב-`Base.astro` אך ורק בשביל ווידג'ט הנגישות, שבודק
במפורש שהגרסה 3 ומעלה. שום קוד אחר באתר לא משתמש בו. מחיקה תפיל את
כפתור הנגישות בשקט, בלי שגיאה בקונסול.

**`strike-pins.mp4`.** חייב להיות מוגש מאותו דומיין. הוצאת הרקע קוראת
פיקסלים מה-canvas, וקובץ מ-CDN חיצוני יזהם אותו והדפדפן יחסום את הקריאה.

**כותרת יחידה.** הכיתוב "מרכז פנאי ובילוי" בהדר הוא `span` ולא `h1`.
ההדר חוזר בכל עמוד, אז `h1` שם היה יוצר כותרת ראשית כפולה בכל עמוד.

**גדלי קבצים.** גיטהאב חוסמת קבצים מעל 100MB. הווידאו דחוס בהתאם —
לא להחליף בגרסאות מקוריות בלי לדחוס.

## פתוח

- הטפסים (`צור קשר`, `הרשמה לחוגים`) פותחים וואטסאפ עם הפרטים שמולאו
  (`public/js/site.js`, סעיף 6). אין שרת ואין מייל אוטומטי — מי שרוצה
  שהפניות יגיעו גם במייל צריך לחבר שירות טפסים.
- `public/pdf/Menu102023.pdf` הוא מאוקטובר 2023 וצריך עדכון.
- `src/pages/accessibility.astro` (הצהרת נגישות) מכיל שלושה מקומות מסומנים
  `[להשלים: ...]` — שם רכז/ת הנגישות ופירוט נגישות המתחם. למלא לפני העלייה.
