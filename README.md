# באולינג שערי חדרה — אתר

אתר סטטי בנוי ב-Astro. נפרס אוטומטית לוורסל בכל push ל-main.

## עריכה שוטפת — בלי לגעת בקוד

| מה לשנות | איפה |
|---|---|
| טלפון, פקס, אימייל, כתובת, שעות פתיחה, תפריט ניווט | `src/data/site.json` |
| מחירי ימי הולדת, מה כלול בכל חבילה | `src/data/packages.json` |
| תמונות | `public/images/` — העלאה באותו שם מחליפה |
| קבצי PDF (תפריטים, דפי חבילות) | `public/pdf/` |

שינוי ב-`site.json` מתעדכן בכל ששת העמודים בבת אחת.

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # פלט ל-dist/
```

## פריסה

וורסל: Framework Preset = **Astro**. אין מה להגדיר מעבר לזה.
ההפניות 301 מהאתר הישן (`.asp`) יושבות ב-`vercel.json`.

## מבנה

```
src/data/       תוכן ניתן לעריכה
src/layouts/    Base.astro — כותרת, פוטר, SEO, JSON-LD
src/pages/      ששת העמודים
src/styles/     design.css — גיליון הסגנון מהעיצוב
public/js/      site.js — קרוסלה, תפריט, רצף הסטרייק
public/images/  תמונות
public/pdf/     תפריטים ודפי חבילות
```

## מה עוד פתוח

- הטפסים (`צור קשר`, `הרשמה לחוגים`) הם `action="#"` — צריך חיבור ל-Formspree או דומה
- 8 עמודי האירועים בתפריט מצביעים ל-`#` — אין להם עדיין תוכן
- `דרושים עובדים` בדף הבית מכיל מציין מקום לתמונה
- `Menu102023.pdf` הוא מאוקטובר 2023 וכדאי לעדכן
